Information structure
& responsive build

정리되지 않은 자료와 기존 구조를 검토하고, 정보 우선순위와 모바일 사용성을 기준으로 화면을 재구성한 리뉴얼 작업.

RoleScope · UI · BuildPlatformWeb / MobileStatusReal Work

Context

요청을 그대로 옮기기보다,
작업 가능한 구조로 먼저 정리했습니다.

전달받은 자료만으로는 바로 화면을 구성하기 어려웠고, 기존 메뉴 또한 방문자 관점에서 우선순위가 명확하지 않았습니다. 기존 사이트와 업종 특성을 함께 검토해 콘텐츠 범위와 페이지 구성을 다시 정리했습니다.

Problem

01

메뉴와 콘텐츠의 우선순위가 불분명

02

모바일에서 주요 정보 탐색이 어려움

03

기존 자료를 재분류해 사용할 필요

Decision

방문자가 먼저 찾을 정보를 기준으로
구조를 다시 잡았습니다.

기존 메뉴 체계를 그대로 따르지 않고 주요 문의 목적과 정보의 성격을 기준으로 메뉴를 재구성했습니다. 모바일에서는 정보량과 버튼 배치를 조정해 핵심 동선이 먼저 보이도록 정리했습니다.

Design & Build

PC와 모바일 UI를 정리한 뒤 HTML, SCSS, JavaScript 기반으로 반응형 구현하고 CMS에 적용했습니다. 디자인 단계부터 실제 구현 제약과 유지보수성을 함께 검토했습니다.

After Launch

오픈 이후 피드백도
다음 개선으로 연결했습니다.

운영 중 들어오는 수정 요청과 오류를 확인해 실제 화면에 반영하고, 반복되는 이슈는 이후 프로젝트에서 동일한 문제가 발생하지 않도록 작업 기준에 반영했습니다.
