01 / Website Renewal

Information structure & responsive build

정리되지 않은 자료와 기존 구조를 검토하고, 정보 우선순위와 모바일 사용성을 기준으로 화면을 재구성한 리뉴얼 작업.

RoleScope · Planning · UI · BuildPlatformWeb / MobileStatusReal Work

Context

자료와 기존 구조를 먼저 정리해야 했습니다.

전달받은 자료만으로는 바로 화면을 구성하기 어려웠고, 기존 메뉴도 방문자 관점에서 우선순위가 명확하지 않았습니다. 기존 사이트와 업종 특성을 함께 검토해 콘텐츠 범위와 페이지 구성을 다시 정리했습니다.

Problem

01

메뉴와 콘텐츠의 우선순위가 불분명

02

모바일에서 주요 정보 탐색이 어려움

03

제공 자료를 그대로 사용하기 어려움

My Decision

방문자의 탐색 순서를 기준으로 구조를 다시 잡았습니다.

기존 메뉴 체계를 그대로 따르지 않고 주요 문의 목적과 정보의 성격을 기준으로 메뉴를 재구성했습니다. 모바일에서는 정보량과 버튼 배치를 조정해 핵심 동선이 먼저 보이도록 정리했습니다.

Design

정리한 정보 구조를 바탕으로 PC와 모바일 화면을 구성했습니다. 같은 내용을 단순히 축소하기보다, 모바일에서는 우선순위와 동선을 다시 조정했습니다.

Build

설계한 화면을 실제 환경까지 연결했습니다.

HTML, SCSS, JavaScript 기반으로 반응형 화면을 구현하고 CMS에 적용했습니다. 디자인 단계에서 예상했던 구현 제약을 확인하고 필요한 부분은 다시 조정했습니다.

After Launch

오픈 이후의 피드백도 다음 개선으로 연결했습니다.

운영 중 들어오는 수정 요청과 오류를 확인해 실제 화면에 반영하고, 반복되는 이슈는 이후 프로젝트에서 동일한 문제가 생기지 않도록 작업 기준에 반영했습니다.

What I learned

화면을 만드는 일과 운영하는 일은 분리되어 있지 않았습니다.

구현과 운영까지 이어서 경험하면서 초기 화면 설계 단계에서부터 실제 적용 환경과 이후 수정 가능성을 함께 보는 기준이 생겼습니다. 이 경험은 다음 프로젝트에서 문제를 더 일찍 발견하고 판단하는 데 이어지고 있습니다.
