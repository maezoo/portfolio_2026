02 / ABOUT & APPROACH

시작됩니다.

무엇을 더할지보다 왜 필요한지 먼저 생각합니다. 화면의 완성도와 실제 사용 경험을 함께 고려하며, 복잡한 정보를 명확한 구조로 바꾸는 과정에 집중합니다.

웹사이트의 기획부터 정보구조, UI 디자인, 반응형 구현과 운영까지 폭넓게 경험했습니다. 문제를 발견하는 시선과 직접 구현하는 능력을 연결해 더 나은 사용자 경험을 만드는 일을 지향합니다.
