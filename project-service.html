서비스 정보 구조
Website Renewal

여러 페이지에 흩어진 내용을 목적별로 다시 묶고, 주요 서비스에서 문의까지 더 짧게 이어지도록 정리했습니다.

Context

비슷한 내용이 여러 메뉴에 반복되어 처음 방문한 사용자가 어디부터 봐야 할지 알기 어려웠습니다.

Problem

서비스 설명과 문의 동선이 분리되어 탐색 단계가 길고 모바일의 정보 밀도가 높았습니다.

My Decision

콘텐츠를 방문 목적별로 다시 묶고 주요 서비스의 순서와 버튼 위치를 동일한 기준으로 정리했습니다.

Design → Build

콘텐츠 양에 대응하는 유연한 레이아웃으로 설계하고 CMS 환경에서 직접 구현했습니다.

After Launch

오픈 이후 고객 피드백과 오류를 확인해 실제 화면에 반영했습니다.

Improve

운영 중 반복된 문제를 체크리스트로 남겨 다음 프로젝트의 설계와 검수 기준에 반영했습니다.
