How I work

디자인에서 끝내지 않고 실제 브라우저에서 확인합니다.

요청을 정리하고 UI를 설계한 뒤 직접 구현합니다. 반응형과 인터랙션, CMS 환경에서 생기는 제약까지 확인하고 다시 화면에 반영합니다.

  1. 01Request

    요청사항과 필요한 자료를 확인합니다.

  2. 02Scope

    작업 범위와 일정, 필요한 내용을 정리합니다.

  3. 03Plan

    메뉴와 페이지, 콘텐츠 우선순위를 구체화합니다.

  4. 04UI

    PC와 모바일 화면, 상태 변화를 함께 설계합니다.

  5. 05Build

    HTML, SCSS, JavaScript로 레이아웃과 인터랙션을 직접 구현합니다.

  6. 06Launch

    CMS에 적용하고 실제 환경에서 검수해 오픈합니다.

  7. 07Improve

    오류와 수정 요청, 운영 피드백을 다시 개선에 반영합니다.
