Website Renewal 01

기존 사이트의 메뉴와 콘텐츠를 다시 정리하고, 필요한 정보가 더 잘 보이도록 화면 구성을 바꾼 리뉴얼 작업입니다. PC와 모바일 화면을 함께 작업해 실제 사이트에 적용했습니다.

Background

  • 메뉴와 콘텐츠의 우선순위가 분명하지 않았음
  • 모바일에서 원하는 내용을 찾기 어려웠음
  • 제공된 자료만으로는 바로 작업하기 어려워 기존 사이트와 업종을 함께 확인해야 했음

What I Changed

기존 사이트와 전달받은 자료를 다시 확인해 메뉴를 나누고 중요한 내용을 앞쪽에 배치했습니다. 모바일에서는 긴 내용을 줄이고 필요한 버튼이 잘 보이도록 순서를 조정했습니다.

My Role

Process

Focus

Skills

Skills

요청을 처음 확인하고 작업 범위를 정하는 단계부터 UI, 반응형 구현, CMS 적용과 운영까지 실무에서 직접 다뤄왔습니다.

01 / Scope

Project Handling

신규 제작, 리뉴얼, 부분 수정 요청을 확인해 필요한 작업 범위와 견적을 정리합니다. 자료가 부족하면 기존 사이트와 업종을 살펴보고 콘텐츠와 페이지 구성부터 다시 잡습니다.

UI Design

Web Publishing

04 / Operation

Operation & Improvement

오픈 이후 들어오는 수정 요청과 오류를 확인하고, 고객 피드백을 실제 화면에 반영합니다. 운영하면서 반복해서 생기는 문제는 다음 작업에서도 같은 문제가 생기지 않도록 정리해둡니다.
