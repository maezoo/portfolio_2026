How I work

디자인에서 끝내지 않고 실제 화면까지 연결합니다.

요청을 정리하고 UI를 설계한 뒤 직접 구현합니다. 구현 중 확인되는 제약과 운영 이후의 피드백도 다시 화면에 반영합니다.

  1. 01Request

    요청사항과 필요한 자료를 확인합니다.

  2. 02Scope

    작업 범위와 일정, 필요한 내용을 정리합니다.

  3. 03Plan

    메뉴와 페이지, 콘텐츠 우선순위를 구체화합니다.

  4. 04UI

    정보 구조를 바탕으로 PC와 모바일 화면을 설계합니다.

  5. 05Build

    HTML, SCSS, JavaScript로 반응형 화면을 직접 구현합니다.

  6. 06Launch

    CMS에 적용하고 실제 환경에서 검수해 오픈합니다.

  7. 07Improve

    오류와 수정 요청, 운영 피드백을 다시 개선에 반영합니다.

Design to live

Figma에서 설계한 화면을 직접 구현해 실제 사이트로 연결합니다.

반응형, 인터랙션, CMS 구조와 유지보수성을 디자인 단계부터 함께 봅니다. 화면과 실제 결과 사이의 차이를 줄이는 것이 제 작업 방식의 중요한 부분입니다.
