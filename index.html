Website UX Redesign

자료가 충분하지 않은 고객 프로젝트에서 기존 사이트와 업종을 분석하고, 콘텐츠 구조와 화면 우선순위를 직접 정리한 뒤 Figma UI와 반응형 구현까지 연결한 프로젝트.

Problem

  • 콘텐츠와 메뉴의 우선순위가 불명확
