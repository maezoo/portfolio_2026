HOW I WORK

01 · DEFINE

요청을 작업으로 바꾸기

고객 요청을 확인한 뒤 필요한 작업 범위와 견적, 일정부터 정리합니다. 자료가 부족하면 기존 사이트와 업종을 확인해 메뉴와 콘텐츠의 우선순위를 다시 잡습니다.

02 · DESIGN

필요한 정보부터 보이게

전달받은 내용을 그대로 배치하기보다 어떤 정보가 먼저 보여야 하는지 정리하고 PC와 모바일 환경에 맞춰 화면을 구성합니다.

03 · BUILD

실제 구현까지 연결

UI 설계 이후 HTML, CSS/SCSS, JavaScript와 CMS 환경에서 직접 구현합니다. 반응형, 웹표준, SEO와 유지보수 가능성도 함께 확인합니다.

04 · IMPROVE

오픈이 끝이 아닌 작업

오픈 후 들어오는 고객 피드백과 오류를 확인하고 다시 화면에 반영합니다. 반복되는 문제는 다음 작업에서 같은 이슈가 생기지 않도록 기준에 반영합니다.
