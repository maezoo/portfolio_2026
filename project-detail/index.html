Overview

프로젝트 소개

기존 사이트의 오래된 구조와 불명확한 정보 흐름을 개선하고, 기업의 전문성과 핵심 서비스를 직관적으로 전달하는 것을 목표로 진행했습니다. 향후 콘텐츠 추가와 운영을 고려해 공통 요소를 분리하고 CMS 템플릿에 적용할 수 있는 구조로 설계했습니다.

Problem Solving

문제 해결 과정

CMS 환경에서는 페이지마다 공통 코드를 직접 반복하면 유지보수가 어려워집니다. 헤더, 푸터, 공통 컴포넌트의 클래스 규칙을 통일하고, 페이지별 스크립트가 공통 동작과 충돌하지 않도록 역할을 분리했습니다. 또한 이미지와 텍스트 길이가 달라져도 카드 높이와 정보 구조가 무너지지 않도록 CSS Grid와 유연한 레이아웃을 적용했습니다.
