PRODUCT DESIGN CASE STUDY

전문가 중심 행정정보를
사용자의 의사결정 경험으로.

동감 행정사사무소의 기존 홈페이지를 단순히 시각적으로 새로 만드는 것이 아니라, 검색·광고 유입 이후 사용자가 자신의 상황을 이해하고, 필요한 정보를 확인하고, 준비된 상태로 상담까지 이어질 수 있도록 전체 경험을 재설계하는 프로젝트입니다.

Role · Product Design / UX / UI / PublishingScope · IA · User Flow · Consultation UX · ResponsiveStatus · Hypothesis-driven redesign

WHY THIS PROJECT

“홈페이지가 낡았다”가
출발점이 아니었습니다.

USER

사용자는 무엇을 알고 싶은가?

내가 어떤 업무에 해당하는지, 무엇을 준비해야 하는지, 나와 비슷한 사례가 있는지, 그리고 어느 순간 전문가에게 도움을 요청해야 하는지 알고 싶습니다.

BUSINESS

운영자는 무엇을 필요로 하는가?

광고와 검색으로 들어온 방문자가 전화 상담까지 자연스럽게 이어지고, 상담 전에 핵심 정보가 정리되어 반복 질문이 줄어드는 구조가 필요합니다.

CORE PROBLEM

서비스는 찾을 수 있지만,
이해 → 판단 → 상담의 연결이 약했습니다.

“사용자가 서비스를 못 찾는 것이 아니라, 찾은 뒤에도 자신의 상황을 해석해야 하고 다음 행동을 스스로 조립해야 한다.”

OBSERVATIONS

대화와 실제 화면에서 좁혀진 6가지 문제

01

전문가 중심 상세정보

구비서류와 법률 문구가 원문 중심으로 나열되어 비전문 사용자가 “그래서 나는 뭘 해야 하는지” 판단하기 어렵습니다.

02

불명확한 상담 CTA

전화번호는 노출되지만 버튼처럼 인지되지 않고, 최근까지 서브페이지에서는 즉시 전화하는 경로가 부족했습니다.

03

내부 업무분류형 IA

서비스, 정보성 콘텐츠, 절차 설명이 같은 메뉴 레벨에 섞여 사용자 관점의 탐색 기준이 일관되지 않습니다.

04

사례 콘텐츠의 정체성 부족

‘해결사례’와 ‘동감갤러리’가 따로 존재하지만 둘 다 실제 업무결과와 증빙을 보여주는 역할에 가깝습니다.

05

모바일 탐색 부담

작은 글자와 큰 이미지가 화면을 차지하고, 갤러리는 이미지 1개씩 긴 스크롤을 요구해 빠른 비교가 어렵습니다.

06

소개와 문의의 목적 혼재

행정사 소개와 문의가 한 페이지에 함께 있어 ‘신뢰 확인’과 ‘행동 수행’이라는 서로 다른 목적이 섞여 있습니다.

DESIGN CHALLENGE

어떻게 하면 사용자가
전문용어를 몰라도 다음 행동을 선택할 수 있을까?

리뉴얼의 목표는 문의를 줄이는 것이 아닙니다. 행정서비스 특성상 전화 상담이 서비스 과정의 일부라고 보고, 상담 전에 사용자가 자신의 상황을 이해하고 준비할 수 있도록 온라인 경험을 설계합니다.

검색·광고 유입→상황 기반 탐색→핵심 정보 이해→유사 사례 확인→상담 준비→전화·맞춤 상담
