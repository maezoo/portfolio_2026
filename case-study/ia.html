행정심판 메뉴는 왜 줄였나?

현재

음주운전구제 / 처벌·벌금 / 구제조건 / 영업정지 / 학교폭력 / 재심청구 / 행정심판이 동일 레벨에 존재합니다.

개선

음주운전 구제 / 영업정지 대응 / 학교폭력 행정심판을 서비스로 두고, 처벌·벌금·구제조건은 각 상세페이지의 정보 콘텐츠로 이동합니다.

사용자 흐름도 다시 설계합니다.

BEFORE

검색·광고→메인→업무 메뉴 탐색→전문정보 해석→궁금증 발생→연락처 재탐색→문의

AFTER

검색·광고→상황으로 서비스 선택→핵심 정보 이해→유사 사례 확인→상담 내용 정리→전화·맞춤 상담

최종 화면 구조

메인

Hero → 상황 기반 서비스 탐색 → 주요 서비스 → 진행과정 → 업무사례 → FAQ → 맞춤상담 → 전화 CTA

서비스 상세

대상 여부 → 핵심 준비사항 → 진행 절차 → 상황별 예외 → 유사 사례 → 맥락형 상담 CTA

업무사례

분야별 필터 → 결과 요약 → 상세 내용 → 허가증·등록증 증빙 이미지

맞춤상담

업무 선택 → 현재 단계 → 신청 주체 → 자유 입력 → 상담 요약 → 전화/문의 연결
